# Kumar Agro Tourism

A premium, photography-led countryside day-out website for Kumar Agro Tourism in Dondaicha, Maharashtra.

## The website

A cinematic photographic hero, editorial nature-and-adventure sections, authentic imagery from the Kumar brochure, full-day visit packages, group enquiries, itinerary and WhatsApp booking links. Designed to work beautifully on mobile and desktop, without 3D/WebGL, a database or paid services.

## Local development

Requires Node.js 22 or newer.

```bash
npm install
npm run dev
```

Production build: `npm run build` (output: `dist/`).

## Hosting

Cloudflare Pages is connected to the `main` branch of this repository and deploys the Vite `dist/` build automatically. Production: https://kumar-agro-tourism.pages.dev/.

- **Kaanan by KS Resort:** `/resort` — a new, independent premium resort and wedding-venue landing page.
- Visitors can switch between the two experiences using the destination slider on both pages.
- Vite builds two HTML entry points, so shared resort URLs receive their own page title, social preview, and description.
